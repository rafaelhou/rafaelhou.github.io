# 三上詩詞 · 一學年 23 首

115 學年度三上的詩詞背誦教材整理。老師發的一覽表是紙本 + QR-Code，
這裡把它變成**點得下去**的網頁，並補上每首詩的原文注音、白話，
以及「作者當時在想什麼」。

**線上瀏覽**：https://rafaelhou.github.io/poems/

---

## 四個分頁

| 分頁 | 內容 |
|---|---|
| 進度表 | 老師排定的 23 首背誦順序，含四個期中考暫停週。**這一頁可以直接列印**，貼在教材最前面 |
| 23 首詩 | 每首：原文（逐字注音）、白話、作者在想什麼、難字小教室、影片連結。可搜尋、可依朝代篩選 |
| 作者 | 17 位作者小檔案：是誰、活在什麼時候、寫詩時在想什麼、這學期要背他哪幾首 |
| 怎麼用 | 給家長的規劃建議：暑假先看影片、開學每週一首、期中考那四週拿來複習 |

## 資料從哪來

**週次、序號、詩名、作者、影片連結**：老師的一覽表（`115學年度三上詩詞學習一覽表`）。
表上的影片是 QR-Code，用 OpenCV 的 `QRCodeDetector` 全部解碼後比對位置寫進 `data.js`，
所以網頁上可以直接點，不用拿手機掃。第 4 頁那 11 支「作者介紹」影片也一併對應到作者。
〈春日〉在原表上註明「無」，所以沒有連結。

**注音**：先用 `pypinyin` 的 `Style.BOPOMOFO` 產生，再**逐字校對**破音字與變調。
校過的包括：單于 ㄔㄢˊ、彈琴 ㄊㄢˊ、長嘯／長雲 ㄔㄤˊ、數重山 ㄔㄨㄥˊ、
堅勁 ㄐㄧㄥˋ、門泊／舟泊 ㄅㄛˊ、一行 ㄧˋ ㄏㄤˊ、此曲 ㄑㄩˇ、終不還／照我還 ㄏㄨㄢˊ，
以及「一」「不」的變調。**如果跟課本不同，以課本為準。**

**白話、作者的想法、難字**：為了讓三年級讀得懂而寫的，不是課本內容。

## 設計取捨

**注音直排在字的右邊，不用 `<ruby>`。** `ruby-position: inter-character`（專為注音設計的值）
瀏覽器支援度不一致，所以改用 `inline-flex` 加 `writing-mode: vertical-rl` 自己排——
在所有瀏覽器都是課本上那個樣子。

**注音可以關掉。** 剛開始開著讀，背熟了關掉自己念，可以檢查是不是真的記得。
狀態存在 `localStorage`。

**原文用楷體／明體，說明用黑體。** 一眼就分得出「這是詩」和「這是別人寫的解釋」。

**列印只印進度表。** 老師說表格要貼在教材最前面，所以 `@media print` 只留那張表，
而且**在紙上印出 `youtu.be/xxxx` 短網址**——紙本點不了連結，要看得到網址才打得出來。

**同一週內的順序照老師的表。** 第 20 週是 楓橋夜泊 → 畫眉鳥 → 泊船瓜洲 → 春日，
序號並非遞增，所以排序只比週次，靠 JS 穩定排序保持原順序。
