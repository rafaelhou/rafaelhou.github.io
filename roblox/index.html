FROM PLAYER TO MAKER

你已經會玩了。
下學期開始，換你做。

你在 Roblox 上玩過的每一個遊戲，都是某個人做出來的——有些是公司， 但有很多是跟你差不多大的小孩。他們用的工具你等一下就會裝好，而且是免費的。

這本手冊不會幫你把遊戲做完。它是你卡住的時候可以翻回來的地方： 英文名詞看不懂、程式跑不動、忘記下一步要做什麼，都來這裡找。

01先搞懂：Roblox 有兩個

很多人以為「學 Roblox」是學怎麼玩。不是。你要學的是右邊那個。

玩的那個

Roblox

手機、平板、電腦都能開

  • 玩別人做的遊戲
  • 跟朋友一起跑跳
  • 你現在做的事
做的那個

Roblox Studio

只有 Windows 和 Mac 電腦能裝，平板做不了

  • 蓋 3D 場景、放積木
  • 寫程式讓東西會動
  • 發布出去給全世界玩

順帶一提：做遊戲的時候你是一個人在電腦前面工作的，不會跟陌生人聊天。 Studio 是一個安靜的工具，跟你平常玩的那個熱鬧的 Roblox 不一樣。

02開始前要準備的三樣東西

  1. 一台電腦

    Windows 或 Mac 都可以。iPad 不行——iPad 可以玩 Roblox，但裝不了 Studio。

  2. 一個 Roblox 帳號

    用你現在玩的那個就好。裝 Studio 的時候用同一個帳號登入，做出來的東西才會存在你的帳號下面。

  3. 爸媽把安全設定調好

    這件事讓爸爸做（這頁最下面有給他看的說明）。你只要知道：你的帳號會被設定成小孩帳號， 聊天功能會受限制，這是正常的，不是壞掉。

03Studio 打開長這樣

第一次打開會覺得「怎麼這麼多東西」。其實你只要先認得五塊就夠開始了。

1Viewport 畫面

中間最大那塊。你在這裡蓋東西、轉視角。右鍵拖曳轉頭，W A S D 走動。

2Explorer 總管

右上角的清單。你放進遊戲的每一樣東西都會出現在這裡，像資料夾一樣。

3Properties 屬性

Explorer 下面。選到什麼，這裡就顯示它的顏色、大小、有沒有被釘住。

4Output 輸出視窗

最下面。程式跟你講話的地方，紅字＝出事了。這是你最好的朋友。

▶Play 執行

上面那個綠色三角形。按下去就會變成玩家，可以自己試玩。按 Stop 回來繼續蓋。

04你的第一支程式

目標很小：做一個踩到會變色的積木。做完這個，你就懂了 Roblox 程式的一半。

  1. 放一個積木

    工具列 Model → Part。它會出現在畫面中間。

  2. 把它釘住

    在 Properties 裡找到 Anchored，打勾。沒打勾的話一按 ▶ 它就掉下去了。

  3. 塞一個腳本進去

    在 Explorer 對著這個 Part 按 ＋ → Script。它會自動打開，裡面已經有一行 print("Hello world!")。

  4. 把裡面的字換成這段 
    -- 這個腳本住在哪個積木裡
local part = script.Parent

part.Touched:Connect(function(hit)
  part.BrickColor = BrickColor.new("Bright red")
  print("有人踩到我了")
end)
  5. 按 ▶ 然後去踩它

    積木變紅色，Output 出現「有人踩到我了」。成功了。

看懂這五行，比抄對它重要。 第一行是「找到我住的積木，叫它 part」。第三行是「當 part 被碰到的時候，做下面這些事」。 中間那兩行就是要做的事。end) 是結尾，忘記寫它程式就會壞。

05Luau 只要先會五件事

Roblox 用的語言叫 Luau。它跟你可能玩過的積木式程式（Scratch）不一樣，要自己打字。但要記的東西沒有想像中多。

① 取名字 local

把一個東西取一個短名字，之後就用這個名字叫它。

local door = script.Parent
local speed = 16

② 如果 if

條件成立才做。注意結尾要有 end。

if speed > 20 then
  print("太快了")
end

③ 重複 for

數著做幾次。task.wait(1) 是等一秒。

for i = 1, 3 do
  print("倒數 " .. i)
  task.wait(1)
end

④ 事件 :Connect()

「當某件事發生的時候」。Roblox 大部分的程式都長這樣。

part.Touched:Connect(function(hit)
  print("碰到了")
end)

⑤ 一包事情 function

把常做的事包起來取名字，之後叫名字就好。

local function boom()
  print("爆炸")
end

boom()

兩個會害你很久的小事

大小寫算不一樣。 part 和 Part 在 Luau 是兩個不同的東西。

舊教學會寫 wait()。 現在請寫 task.wait()，比較準也比較不會出問題。

06程式不動的時候

第一件事永遠是：看 Output 視窗。紅色的字是程式在告訴你哪裡壞了。

attempt to index nil with 'Touched'

意思：我找不到你說的那個東西。
通常是：名字打錯了，或是東西不在你以為的地方。回 Explorer 對一下名字。

Expected 'end' (to close 'function')

意思：你少寫了結尾。
通常是：end 或 end) 忘了寫。每個 function、if、for 都要有一個 end 收尾。

（沒有紅字，但什麼事都沒發生）

意思：程式根本沒跑到。
怎麼查：在第一行加 print("我有跑")，按 ▶。沒印出來＝腳本放錯地方了。

積木一按 ▶ 就掉下去

意思：忘了 Anchored。
修法：Properties → Anchored 打勾。這是所有人的第一名錯誤，你不孤單。

問問題的順序：① 看 Output ② 加 print 找出跑到哪一行 ③ 回來翻這本手冊 ④ 問老師或爸爸。前三步自己做過，第四步問出來的問題會好很多。

10玩什麼比較好

Roblox 上有幾千萬個遊戲，好壞差很多。這份清單的標準是三件事： 不花錢也玩得下去、開一局就能玩、跟同學一起玩最有趣。 最紅的不一定最適合你——所以人氣不是我挑的理由。

很紅，但玩之前要先知道

這三款同時在線都是幾十萬人，同學一定會提到。不是不能玩，是玩之前要先懂它的問題在哪。

11會用到腦袋的那幾款

這幾款的前十分鐘可能有點悶，撐過去就不一樣了。它們會用到你在這本手冊裡學的東西—— 或者反過來，讓你更想學。第一款根本不是遊戲，是一堂真的在教 Luau 的課。

給爸爸媽媽：2026 年的 Roblox 安全設定

2026 年 1 月 7 日起，聊天功能需要通過年齡驗證，全球適用。 方式是臉部年齡估計：錄一段自拍影片，由第三方服務判斷年齡區間，不需要證件； Roblox 表示影像在處理後即刪除。

驗證後會被分到六個年齡層之一（Under 9／9–12／13–15／16–17／18–20／21+）， 只能跟同一層或相鄰層的人用文字聊天；沒有通過驗證的帳號，聊天功能會整個關閉。

家長控制已改為用家長自己的帳號連結管理，不再是四位數 PIN。 可以封鎖特定遊戲，管控範圍延長到 16 歲。

對這本手冊的影響：沒有。Roblox Studio 是本機的開發工具， 做遊戲的過程不涉及跟陌生人互動。真正要先設定好的是付款與 Robux 消費限制。
