# 打字小英雄 · Type Hero

給小學生的英文打字練習。畫面下方有一整排鍵盤，會亮起**下一個要按的鍵**，
顏色就是**該用哪一根手指**。不需帳號、不上傳資料，什麼都不存。

**線上瀏覽**：https://rafaelhou.github.io/typing-hero/

---

## 五個關卡

| 關卡 | 練什麼 | 例句 |
|---|---|---|
| 1 主排鍵 | 手指不離開 home row 的 8 顆鍵 | `asdf jkl; asdf jkl;` |
| 2 認識字母 | 26 個字母走一遍，手指上下跑 | `the quick brown fox` |
| 3 簡單單字 | 一次打完一整個認識的字 | `red blue green pink` |
| 4 學校單字 | 三年級課本裡會用到的字 | `book pencil ruler eraser` |
| 5 短句挑戰 | 大寫與標點，開始用到 Shift | `My name is Type Hero.` |

打完一關給 1～3 顆星：正確率 90% 且 12 WPM 給兩顆，96% 且 20 WPM 給三顆。
**門檻刻意讓正確率先滿足**——這個年紀先求打對，速度自己會來。

## 設計取捨

**十根手指各有顏色，鍵盤上一直看得到。**
每顆鍵底部有一條該手指的顏色線，下一個要按的鍵則整顆亮成那個顏色，
旁邊的文字提示也用同一個色塊寫「左手無名指」。孩子不用記表格，
顏色一致就會慢慢對起來。F 和 J 畫了小凸點，對應真實鍵盤上的定位點。

**大寫和標點會同時亮兩顆鍵。**
打 `M` 時亮 `m` 和**左邊**的 Shift——因為 `m` 是右手，Shift 要另一手壓。
這是打字教學裡最容易被跳過、但錯了很難改的一件事。

**中文輸入法沒切掉時，明講怎麼辦。**
IME 沒關掉時瀏覽器送來的是 `Process` / `Unidentified` 或非 ASCII 字元，
偵測到就跳一條橫幅寫「按 Shift 切成英文」，而不是靜靜地什麼都不發生——
小孩遇到這個只會以為鍵盤壞了。打對第一個字後橫幅自動消失。

**打字區固定是深色的。**
淺色主題下整頁是亮的，只有那塊「螢幕」是深的。它是一台機器的螢幕，
不隨主題翻轉，視線也比較容易固定在那裡。其餘介面跟隨系統的淺色／深色。

**Backspace 會把統計一起退回去。**
刪掉一個字元時，正確數、錯誤數、總按鍵數都跟著減。不這樣做的話，
「打錯→退格→改對」會被算成一次錯誤，孩子照著正確流程做卻被扣分。

**前兩關沒有空白。**
Level 1、2 是純字母練習，每一行都連在一起（`asdfjkl;asdfjkl;`、`abcdefghijkl`），
手指還在學字母位置的階段，中間插一顆大拇指只是打斷節奏。
Level 3 之後是真正的單字和句子，空白照打。
不該打空白的地方按到空白鍵會被當作沒按，不算打錯。

**音效用 Web Audio 現場合成，不放音檔。**
打對 880Hz 短音、打錯低沉的鋸齒波、整行完成一個上揚音、過關三連音。
零檔案、零載入，右上角可以關掉。

**這是給實體鍵盤用的。**
手機沒有實體鍵盤，這頁也就不特別叫出虛擬鍵盤——用觸控螢幕練指法沒有意義。
平板接了藍牙鍵盤可以正常玩。

## 檔案

```
index.html    版面
style.css     主題變數、鍵帽形狀、深色螢幕
app.js        關卡資料、指法對照表、打字判定與計分
counter.js    Supabase 訪問計數（與其他站共用專案，以 COUNTER_ID 區分）
favicon.svg
```

無建置步驟，純靜態。改 `app.js` 最上面的 `LEVELS` 就能加關卡或換句子。
